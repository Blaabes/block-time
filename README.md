# Block Time

A small, offline-first flight-time toolkit for airline pilots. Installable
web app (PWA) — no account, no server, no data leaves your device.

- **Calc** — HH:MM tape calculator (type `130`, get `1:30`).
- **Elapsed** — time between two Zulu times, with midnight rollover.
- **Flt Plan** — leg-by-leg times with a running total and ETAs. Built for
  minimum keystrokes: two digits and it advances.
- **Crew Rest** — rest rotations for 3- or 4-pilot crews, with a timeline.

Zulu-first throughout; set a local offset in settings if you want both.

## Install

Open the site, then:

- **iPhone/iPad** — Share → *Add to Home Screen*. Install it rather than
  bookmarking it: iOS clears data for uninstalled sites after about a week.
- **Android** — Chrome offers *Install app*, or use ⋮ → *Add to Home screen*.

Once installed it runs fully offline. The network is only needed to install
or to pick up an update.

## Privacy

All settings and data stay in your browser's storage on your device. There
is no backend and nothing is uploaded. Optional sync, if you turn it on, is
to a server you choose and configure yourself.
