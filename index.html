Crew sync (WebDAV) — optional

Just the https:// host is enough. Folder is the path from your Nextcloud root, no leading slash — e.g. Obsidian/MyVault/Crew.

Works with Nextcloud, ownCloud, Synology and anything else speaking WebDAV. Use an app password, never your account password — it is stored only on this device and you can revoke it on the server. Newest edit wins, per person, so notes made in Obsidian and notes made here both survive. Use a folder of its own — the one holding your crew notes, not your notes in general: files here get written back in this app’s format. As a safety net, any file without tags: [crew] in its frontmatter is ignored rather than rewritten.

“Could not reach it at all” is almost always CORS, and an app password does not help with it — two different things with confusingly similar names. The password is your credential; CORS is your server deciding whether a web page from somewhere else may talk to it at all, which it settles before any password is looked at. A wrong password gives a clean 401 instead. Fix it on the server: on Nextcloud install the WebAppPassword app (an add-on that sends CORS headers — it does not manage passwords) and allow this site’s address, or add the headers in your reverse proxy. A login gateway in front, such as Cloudflare Access, blocks it identically and no CORS setting will help.
